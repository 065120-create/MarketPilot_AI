# System Limitations

While MarketPilot AI demonstrates advanced multi-agent orchestration, several limitations exist in the current prototype.

## Synthetic Data
- **Limitation:** The demo primarily relies on synthetic/sample CSV data.
- **Impact:** Real-world marketing data from platforms like Meta or Google Ads is often much messier, containing hundreds of highly correlated columns that may confuse the Data Analyst agent without further prompt tuning.

## LLM Dependency and Latency
- **Limitation:** The system is heavily dependent on OpenAI's GPT-4o API.
- **Impact:** Multi-agent workflows require sequential LLM calls. The Analyst must finish before the Strategist begins, which then must be checked by the Validator. This can result in wait times of 15-30 seconds per campaign request.

## Prediction Uncertainty
- **Limitation:** AI-generated ROI predictions are highly speculative.
- **Impact:** While grounded in past data via RAG, the LLM cannot guarantee future market conditions. Predictions should be treated as directional estimates, not guarantees.

## RAG Knowledge Scope
- **Limitation:** RAG is currently limited to text extraction from PDFs and TXTs.
- **Impact:** Visual charts or complex tables embedded in uploaded historical PDF reports may be parsed incorrectly, leading to missing context for the Strategist agent.

## Scalability (CSVs)
- **Limitation:** Agents process data by reading summaries generated by pandas/Python tools.
- **Impact:** If a user uploads a 1GB CSV, the system cannot feed the entire file into the LLM context window. It relies on the tool to generate statistical summaries (mean, sum, max), which may obscure long-tail insights.

## Cost Considerations
- **Limitation:** Multi-agent workflows consume significantly more tokens than simple chat interfaces.
- **Impact:** Heavy usage, especially with large contexts (RAG), can lead to rapid accumulation of API costs.

## Security Gaps in Prototype
- **Limitation:** The current iteration lacks robust user authentication (JWT/OAuth).
- **Impact:** Anyone with access to the UI can trigger agent workflows and potentially execute n8n webhooks. Not suitable for public deployment without adding an auth layer.
